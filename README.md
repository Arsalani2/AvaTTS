## 📖 درباره پروژه

**AvaTTS** یک اپلیکیشن مدرن اندرویدی است که با هدف رفع محدودیت‌های تبدیل متن طولانی به گفتار طراحی شده است. بسیاری از سرویس‌های TTS متون طولانی را نمی‌پذیرند یا سقف کاراکتر دارند. AvaTTS با تکیه بر **بخش‌بندی هوشمند متن**، **گاوصندوق امن چندکلیدی با قابلیت چرخش خودکار و مدیریت خنک‌سازی (Cool-down)** و **سرویس پس‌زمینه پردازش دسته‌ای**، امکان تولید کتاب‌های صوتی، پادکست‌ها، مقالات و محتوای آموزشی را با بهترین کیفیت و بدون توقف فراهم می‌سازد.

## ✨ ویژگی‌های کلیدی

### 🎙️ ۱۲ گوینده رسمی و فوق طبیعی گوگل (Gemini TTS)
- **۶ صدای زن:**
  - `Kore`: لحن آرام، متین و مناسب برای کتاب‌های داستانی
  - `Aoede`: رسا، شفاف و عالی برای اخبار و متون علمی
  - `Leda`: مهربان، گرم و جذاب برای پادکست
  - `Callisto`: حماسی، قدرتمند و تاثیرگذار
  - `Erin`: جوان، شاداب و پویا
  - `Vega`: رسمی، جدی و باوقار
- **۶ صدای مرد:**
  - `Puck`: باانرژی، هیجان‌انگیز و مناسب روایت
  - `Charon`: عمیق، پرصلابت و صدای بَم گیرا
  - `Fenrir`: قدرتمند، رسا و باابهت
  - `Zephyr`: ملایم، روان و آرامش‌بخش
  - `Orus`: رسمی، شمرده و اداری
  - `Enif`: گرم، صمیمی و دوستانه

### 🔐 گاوصندوق کلیدهای API (Vault)
- ذخیره‌سازی نامحدود کلیدهای Google Gemini API
- **رمزنگاری سطح بالا:** کلیدها به صورت محلی با استاندارد `AES-256-GCM` بر روی خود دستگاه محافظت می‌شوند و هرگز به سرور دیگری ارسال نمی‌گردند.
- **توزیع بار هوشمند (Load Balancing & Rotation):** در صورت رسیدن به سقف مصرف یک کلید (Rate Limit 429)، برنامه به صورت خودکار وارد فاز خنک‌سازی (Cool-down) شده و کار را با کلید فعال بعدی بدون قطعی ادامه می‌دهد.
- امکان فعال/غیرفعال کردن دستی، لغو خنک‌سازی، ویرایش، حذف و سنجش سلامت کلیدها.

### ✂️ بخش‌بندی هوشمند و پردازش دسته‌ای
- تقسیم متون طولانی به قطعات استاندارد بر اساس جملات، علائم نگارشی و پاراگراف‌ها با رعایت مرزهای معنایی.
- امکان ویرایش متن هر بخش به صورت مجزا، تغییر گوینده برای بخش خاص یا تبدیل تکی/دسته‌ای.
- سرویس پس‌زمینه اندروید (Foreground Service) جهت ادامه تبدیل حتی با خروج از برنامه و قفل شدن صفحه نمایش.

### 📊 نمودار زنده پیشرفت (خطی و دایره‌ای)
- **نمودار خطی قطعه‌ای (`🟰🟰➖🟰`):**
  - 🟢 **سبز:** بخش‌های تبدیل‌شده و فایل‌های صوتی آماده
  - ⚪ **سفید/روشن:** بخش‌های در انتظار و در صف تبدیل
  - 🔴 **قرمز:** بخش‌هایی که در حین تبدیل با خطا مواجه شده‌اند
- **نمودار دایره‌ای:** نمایش درصد پیشرفت کلی با انیمیشن روان و امکان سوئیچ لحظه‌ای بین حالت خطی و دایره‌ای.

### 📁 مدیریت فایل‌ها و ادغام صوتی (Audio Merge)
- ادغام تمام قطعات صوتی تولید شده در یک فایل نهایی صوتی یکپارچه با فرمت استاندارد WAV.
- امکان تعیین پوشه دلخواه ذخیره‌سازی از طریق انتخاب‌گر پوشه حافظه اندروید (`Storage Access Framework`).
- دکمه کپسولی دسترسی سریع به پوشه فایل‌ها در تب پروژه‌ها و لاگ‌ها برای باز کردن مستقیم در فایل منیجر گوشی.

### 📝 سیستم جامع «گزارش‌ها» (Activity Logs)
- گزارش‌گیری زنده و تفکیک‌شده برای هر پروژه شامل:
  - زمان دقیق ساخت و تغییر نام پروژه‌ها
  - وضعیت دانلود هر قطعه از گوگل با **حجم دقیق داده مصرفی** (KB / MB)
  - مسیر دقیق ذخیره‌سازی فایل‌ها روی حافظه با دکمه دسترسی مستقیم به فایل
  - نتیجه خطایابی و جزئیات رفع مشکل در صورت رخداد خطا

## 🛠️ معماری و پشته فناوری

```
AvaTTS Architecture
┌────────────────────────────────────────────────────────┐
│             UI Layer (Jetpack Compose M3)              │
│    StudioScreen │ ProjectsScreen │ LogsScreen │ SettingsScreen │
└───────────────────────────┬────────────────────────────┘
                            │ StateFlow / Events
┌───────────────────────────▼────────────────────────────┐
│                  ViewModel & State                     │
│         StudioViewModel │ ProjectsViewModel │ ...       │
└───────────────────────────┬────────────────────────────┘
                            │ Repository Pattern
┌───────────────────────────▼────────────────────────────┐
│                    Data & Engine Layer                 │
│  AppRepository │ TtsQueueEngine │ TtsQueueService      │
└─────────────┬─────────────────────────────┬────────────┘
              │                             │
   ┌──────────▼──────────┐       ┌──────────▼──────────┐
   │ Local Room Database │       │  Google Gemini API  │
   │  (Encryption/Vault) │       │ (REST / Audio PCM)  │
   └─────────────────────┘       └─────────────────────┘
```

- **زبان توسعه:** ۱۰۰٪ کاتلین (Kotlin)
- **فریم‌ورک رابط کاربری:** Jetpack Compose با طراحی Material Design 3 (پشتیبانی کامل از حالت تاریک/روشن و تم اختصاصی)
- **پایگاه داده محلی:** Android Room با پشتیبانی از مایگریشن امن پایگاه داده
- **مدیریت همزمانی:** Kotlin Coroutines و Reactive Kotlin Flow
- **سرویس‌های سیستم:** Android Foreground Service، اعلان‌های پیشرفته صوتی، FileProvider امن، و نوتیفیکیشن اختصاصی
- **امنیت:** Android Keystore و EncryptedSharedPreferences

## 🚀 پیش‌نیازها و راه‌اندازی

### پیش‌نیازهای سیستمی
- نصب **Android Studio Ladybug (2024.2.1)** یا نسخه‌های جدیدتر
- **JDK 17** یا بالاتر
- دستگاه فیزیکی یا امولاتور با **اندروید 8.0 (API 26)** به بالا

### مراحل دریافت و اجرای پروژه

۱. **کلون کردن مخزن:**
```bash
git clone https://github.com/YOUR_USERNAME/AvaTTS.git
cd AvaTTS
```

۲. **پیکربندی متغیرهای محیطی:**
یک فایل به نام `.env` در ریشه پروژه ایجاد کنید (می‌توانید از نمونه `.env.example` استفاده کنید):
```env
# اختیاری: کلید پیش‌فرض در صورت عدم استفاده از گاوصندوق
GEMINI_API_KEY=your_gemini_api_key_here
```

۳. **بیلد پروژه و اجرای آزمون‌ها:**
```bash
# اجرای تست‌های واحد (Local JVM Tests)
gradle testDebugUnitTest

# ساخت نسخه اشکال‌زدایی (Debug APK)
gradle assembleDebug
```
فایل نصبی تولید شده در مسیر زیر قرار خواهد گرفت:
`app/build/outputs/apk/debug/app-debug.apk`

> **ساخت ریلیز لوکال (اختیاری):** بیلد ریلیز فقط زمانی امضا می‌شود که متغیرهای محیطی `KEYSTORE_FILE`، `KEYSTORE_PASSWORD`، `KEY_ALIAS` و `KEY_PASSWORD` تنظیم شده و فایل keystore واقعاً موجود باشد؛ بدون آن‌ها خروجی unsigned ساخته می‌شود. clone تازه بدون هیچ فایل keystore، هم `assembleDebug` و هم `assembleRelease` را بدون خطا بیلد می‌دهد (CI همین متغیرها را از Secrets می‌خواند).

## 🔑 دریافت کلید API گوگل (کاملاً رایگان)

برای استفاده از هوش مصنوعی تبدیل متن به گفتار:
1. به سایت [Google AI Studio](https://aistudio.google.com/) بروید.
2. با حساب کاربری گوگل خود وارد شوید و دکمه **Get API key** را بزنید.
3. کلید ساخته شده را کپی کرده و در برنامه AvaTTS وارد تب **تنظیمات** -> بخش **گاوصندوق کلیدها** شده و دکمه «افزودن کلید جدید» را لمس کنید.
4. *نکته حرفه‌ای:* می‌توانید چندین کلید بسازید و همه را اضافه کنید تا برنامه با مدیریت هوشمند نوبت‌ها، ساعت‌ها بدون وقفه برای شما صوت تولید کند!
